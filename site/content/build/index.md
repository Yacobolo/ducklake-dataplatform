# Build

This section teaches QuackStack as one continuous builder workflow:

1. register or select source data
2. shape it with models, macros, and notebooks
3. define orchestration, checks, and freshness
4. publish semantic entrypoints
5. package the result as a data product
6. manage it declaratively over time
