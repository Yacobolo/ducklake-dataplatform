# Build Data Products

Duck combines governed data objects, policy enforcement, and flexible execution. To build effectively on the platform, separate what users consume from how builders define and govern it.

## Concept Map

- Objects live in catalogs, schemas, tables, views, volumes, models, notebooks, assets, and related resources.
- Identity and governance decide who can see which outputs.
- Declarative workflows help builders manage state safely over time.
- Query and compute routing decide where work runs, but governance remains centralized.
